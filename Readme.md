# CI/CD Pipeline for Web Application Deployment on AWS

## Project Overview
Automated CI/CD pipeline using Jenkins, GitHub,
Docker and Amazon ECR.

## Technologies
- AWS EC2
- Amazon ECR
- AWS IAM
- Docker
- Jenkins
- GitHub
- Linux
- Python Flask

## Pipeline Stages
1. Source Code Checkout
2. Docker Image Build
3. Docker Image Push to Amazon ECR

## Deployment
Containerized web application deployed on AWS EC2.

## Application Port
5000
